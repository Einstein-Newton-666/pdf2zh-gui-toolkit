## 三、根因（一句话）

BabelDOC 把 `/Rotate 90|270` 页面的 CropBox 旋转到显示坐标系时，**连原点一起换掉了**
（`(y0, x1, y1, x0)`），导致 `y0` 变成页宽；后端于是给该页每个绘制元素套上
`1 0 0 1 0 -<页宽> cm`，整页内容被平移一个页宽推出页面盒子，被阅读器裁掉。

修复、补丁工具与单元/端到端验证见 [README.md](README.md)。

## 四、science.aeb6744_sm 译文溢边 —— 已修复

### 问题

3 个页面的译文段落被 BabelDOC 排得**远超栏宽**（栏宽 540pt，译文行跑到 615–621pt），
超出页宽 612 的部分被阅读器裁掉，句子看起来被截断：

| 页 | 内容 | 修复前 |
|---|---|---|
| 10 | 正文段落（含 `u_abc` 下标） | 行宽 549pt，溢出页宽 9.3pt |
| 12 | 正文段落（silicone 封装） | 行宽 547pt，溢出 7.95pt |
| 16 | 图 S6 中文图注 | 5 行中 **4 行**溢出，最多 8.3pt |

（最初审计报告写的"溢边 3mm"是按页宽算的；按**栏宽**算实际超宽约 80pt。）

### 修复方式：纯几何压缩，不动一个字符

改写受影响行的文本矩阵：

```
1 0 0 1 <x> <y> Tm   ->   <s> 0 0 1 <x_left + s*(x - x_left)> <y> Tm
```

每个字形以自身原点为中心横向压缩 s，同时位置也按 s 压缩，整行就缩进栏内。
**文字内容、内嵌字体、阅读顺序、文本可提取性全部不变**；原本被裁到页面外的字
反而重新显示出来。

### 验证结果

| 页 | 丢失字符 | 新增可见字符 | 最大右边界 | 溢出行 |
|---|---|---|---|---|
| 10 | **0** | +1（"动"） | 540.0 | 0 |
| 12 | **0** | +1（"脂"） | 540.0 | 0 |
| 16 | **0** | +4（"任器快速"） | 540.0 | 0 |

对照版同步修复：这 3 页按 BabelDOC 原始几何（`show_side_by_side` 的左/右半页 +
`rotate=-90` + 源页 `/Rotate` 置 0）重建。验证**重建后的左半页与旧版逐像素
mad = 0.000**，几何完全一致。
